# Johan Irfan — Portfolio

A modern, high-performance portfolio website built with **Next.js**, **React**, and **Tailwind CSS**.

## Features
- **Requirements Engineering & BA Showcase**: Highlights public sector specifications (BRS, SRS, SDS) from GovTech Malaysia (Kementerian Digital).
- **Featured Projects**: Detailed modals and demos for Full-Stack, 3D Data Visualizations, and UI/UX prototypes.
- **Bilingual Support**: Instant toggle between **English** and **Bahasa Melayu**.
- **Responsive & Accessible**: Optimized for desktop, tablet, and mobile with dark aesthetics.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm start
```
